# Supermart Grocery Sales Dashboard

A beginner-friendly Excel dashboard built for the SapphireIQ student project.
It helps management understand sales, profit, products, discounts and geographic performance.

## Dataset
- 9,994 grocery orders, Jan 2015 – Dec 2018, Tamil Nadu
- Columns: Order ID, Customer, Category, Sub Category, City, Order Date, Region, Sales, Discount, Profit, State

## Objectives
1. Overall sales performance
2. Product performance
3. Profit and discount
4. Geographic performance

## Key findings
- Total sales ₹14,956,982; total profit ₹3,747,121 (25.1% margin)
- Sales grew every year, from ₹2.98M (2015) to ₹4.98M (2018)
- Eggs, Meat & Fish is the largest category (15.2% of sales)
- West is the top region (32.1% of sales); North has only 1 order
- Discount and profit show no relationship (correlation ≈ 0.00)
